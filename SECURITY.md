# Security Policy

## Supported Versions

Currently, only the latest version of Lumina Borealis UI is supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 0.2.x   | :white_check_mark: |
| < 0.2.0 | :x:                |

## Reporting a Vulnerability

We take the security of Lumina Borealis seriously. If you discover a security vulnerability within this project, please **DO NOT** create a public issue.

Instead, please send an email to **kyogantara89@gmail.com**.

We will review the report and respond as quickly as possible. We will keep you updated on the progress of the fix and will credit you for the discovery when the fix is released.
